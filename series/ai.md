# AI 系列：从最简单到深入

每天一篇，中英双语。顺序固定，写完一篇勾一项。不要跳着写，也不要重复已经勾过的题目。

已有的《AI 智能体的执行原理》（`/2026/10/09/ai-agent-execution/`）是中文单篇，不算本系列的第一篇。写到智能体那几篇时可以链接它，仍要按下面的双语格式新写一篇。

## 今天要做的事

1. 读本文件，找到第一项未勾选的题目。
2. 看 `src/content/blog` 里已有文章，确认这个题目还没有发过。发过了就勾上并改做下一项。
3. 用下面的格式写一篇新文章，讲这一个题目。由浅入深，但每一篇自己要能读懂，并在开头用一两句接上上一篇。
4. `npm run build` 必须成功。
5. 把对应条目改成 `- [x]`，并写上发布日期和路径。
6. 只提交这一篇新文章和本文件的改动。直接推送到 `master`。不要开 Pull Request，不要把文章留成 `draft: true`。
7. 清单全部勾完之后，不要停，也不要重写旧题。在清单末尾追加下一个更深入的题目，然后写那一篇。

不要改留言页。不要发明作者的中文姓名。不要把旧文里的个人介绍改回去。

## 文章格式

文件放在 `src/content/blog/YYYY-MM-DD-短英文名.md`。`pubDate` 用运行当天的日期。`slug` 用 `YYYY/MM/DD/短英文名`。

```md
---
title: "中文标题"
description: "中文一句话概括。 English one-sentence summary."
pubDate: YYYY-MM-DD
slug: YYYY/MM/DD/short-english-name
category: AI 系列
tags:
  - AI 系列
  - AI
draft: false
---

AI 系列第 N 篇。上一篇：[标题](/YYYY/MM/DD/slug/)。

## 中文

用一个具体例子把这个概念讲清楚。先说它是什么，再说一次真实的执行里它出现在哪一步，最后说一个常见误会。

## English

A standalone version of the same lesson. Same example, same claims, written in clear English rather than a sentence-by-sentence gloss.
```

中文大约 1200 到 2000 字。英文把同一课讲完，不必逐句对译。不要复制文档或论文原文。
